# M5.7：参考图编辑器工作区与UI制作工作区

更新日期：2026-10-06。状态：方案，未实施、未验收。

本方案替代此前“M5.7：类设计工具编辑画布”的阶段定位。用户图1是整体引擎Editor的
视觉和布局参考，详见[界面参考规范](EDITOR_INTERFACE_REFERENCE.md)。
移除原产品参照，不取消已规划的UI制作能力，不改变M5.1–M5.6的文档/事务/布局/绘制/
文本/运行时输入底座，也不把M5.8组件实例、M5.9语义MCP或M5.10发布验收提前记为完成。
仅更新方案，不授权现在执行M5、不关闭M4 K7及M2/M3开放门禁。

## 1. 新目标

形成与用户图1同一视觉语言的可操作NcmaEngine编辑器：顶部模块/运行工具栏、左侧对象
浏览、中部真实场景或UI画布、右侧Inspector、可折叠AI/工具侧栏、底部资产/Console及状态栏。
场景制作与UI制作作为同一Editor中的不同工作区，不新建引擎入口或第二套编辑命令权威。

保留NcmaEngine名称和现有图标；采用深蓝/炭黑底色、蓝色强调色、细边框、分组工具栏、
明确的选中/禁用/焦点状态。图中文字、品牌、示例性能数字和功能按钮不是实现要求或执行指令。

## 2. 场景工作区

- 顶部：品牌/项目、能力驱动的模块入口、构建/Play/Pause/Step等工具分组。
  只有真实已实现且允许调用的命令可启用，不复制假地形/协作/AI按钮；未实现功能明确禁用或隐藏。
- 左侧：扁平GameObject列表、搜索和分类过滤、持久UUID选择；如做视觉分类，不能保存为
  场景父子树、引入Node或Transform继承，删除分类不能隐式删除对象。
- 中部：真实渲染视口及已有视口操作，不能把参考PNG作为运行背景或可玩场景。
- 右侧：按组件Schema呈现可折叠Inspector、属性草稿和可撤销提交；空对象不自动附加Transform。
- 最右侧：可折叠AI/工具区域，展示实际连接状态、已注册能力、权限/审批和真实结果。
  未接入推理服务时明确显示未接入，不伪造聊天记录、任务结果、多语言游戏脚本或AI服务。
- 底部：资产浏览/工具标签和有界Console，延用实际资产授权与日志分页；缩略图仅在真实
  资产预览通路可用时展示，不借视觉改造宣称完整资产功能已实现。
- 状态栏：项目、真实运行/测量状态；缺失/失效数据标为未测量或不可用，不显示图中FPS120等示例值。

## 3. UI制作工作区（保留原功能，调整界面组织）

- 复用同一顶部工具栏、面板风格和布局框架；中部切换为真实运行时UI预览/编辑画布。
- 左侧显示UI文档内部元素/图层；其内部树独立于场景的扁平GameObject列表，不能混用删除/选择语义。
- 右侧Inspector显示UI布局、样式、文字、字体与资源；底部提供UI资源、诊断和预览尺寸入口。
- 保留画布缩放/平移、选择/多选/框选、拖拽/调整尺寸/二维旋转、对齐/分布/吸附/辅助线、
  层序/显示/锁定/分组、搜索与布局诊断；这些是独立功能，不依赖原产品参照。
- 自动布局参数和分辨率/安全区域预览消费M5.3结果；UI本体消费M5.4/M5.5绘制与文本通路。
  编辑选框/辅助线与运行时UI本体分开，不另写一套只在Editor成立的布局/文本算法。
- UI文档保存/加载、UUID与Undo沿用M5.1/M5.2；组件/变体属于M5.8，授权AI写UI属于M5.9。
  本阶段AI侧栏的布局/接线不提前提供尚未实现的语义修改权限。

## 4. 布局与状态边界

- 大窗口采用对象/画布内容、主视图、Inspector、AI/工具四区；中部优先获得剩余空间。
  侧栏和底部可调整/折叠，小窗口优先折叠AI侧栏或切换标签，不截断Inspector或压扁视口。
- 采用逻辑坐标，依据窗口/DPI/字号重新计算；标题/标签允许换行，输入框维持可操作尺寸。
- 面板尺寸、折叠、主题等本机偏好不写入场景文档，也不污染文档Undo。
  文档属性/画布拖动使用draft；确认只提交一个历史项，Esc/失焦/文档切换或版本冲突取消。
- 工作区切换不Start/Stop/Reload Play、不写World、不转移数值资源所有权；UI画布预览会话
  与活动Play隔离，不通过画布刷新驱动物理或游戏逻辑。
- C#持有布局/选择/草稿/授权/命令业务，原生Dear ImGui只处理复制呈现数据和输入意图。
  GUI事件检查frame/view/document generation/revision，过期、重复、禁用控件事件不能执行。
- 视口Resize/折叠、图像token和GPU目标遵守现有资源pin/设备/generation/帧校验；关闭失败
  保留所有权并禁止依赖卸载。AI/IPC不得阻塞simulation/render tick。
- 自由docking、多文档、云协作、地形编辑、AI推理服务及Vulkan绘制不是本阶段默认交付范围。
  先实现明确、可调整的工作区布局，不以静态截图或控件枚举代替完整功能。

## 5. 内部执行顺序（执行时每个检查点测试）

1. A：统一主题/尺寸/图标呈现与工作区布局状态，先保持现有命令/视口/资源通路不变。
2. B：接入场景工作区、可折叠AI/工具面板和底部区域，基于实际能力/权限决定启用状态。
3. C：接入独立UI制作工作区及既定画布交互，复用M5.1–M5.6底座；缺失前置能力不能用占位图替代。
4. D：完成布局/事件/资源自动回归和可见窗口人工检查，记录未验项，再按批准流程交付。

## 6. 测试与退出门禁

自动检查：

- 1280×720、1920×1080、2560×1440及窄窗口下的布局计算；100%/150%/200%DPI换算、
  面板最小尺寸、折叠、长标签和控件可操作性。
- 对象选择/Inspector/资产/Console/Play实际命令正常；改视觉不产生新的场景权威或历史。
- UI画布拖动/取消/多选/对齐和Undo，Editor/Player同尺寸预览语义一致，保存重启可恢复。
- 过期frame/revision、重复事件、禁用按钮和未授权AI/资产请求不能执行。
- 工作区切换保持Play identity/tick和World不变；Resize不触发数值步，不发生句柄泄漏/旧帧图像复用。
- native/managed插件、M1–M4测试、严格格式/Python inspect/包验证/部署恢复保留。
  使用Build.bat顺序完整Debug/Release回归，新代码零编译警告，相关API validation通过。

人工检查：

- 对照用户图1检查视觉布局，但品牌与语义按现有架构调整，不要求固定像素截图复刻。
- 真机窗口Resize/高DPI、中文输入法、鼠标/键盘焦点、Play/Stop/reload、面板折叠与UI预览。
- AI侧栏展示真实能力/未接入/无授权状态；真实第三方客户端审批验收不由内部事件测试替代。

退出门禁：参考图工作区和UI制作交互有实际运行证据，自动回归通过；人工/环境/性能项逐项
登记，未经验证不记通过。实施小阶段按已授权规则修复失败、测试后提交推送并核对远端SHA；
仅本次修改方案不执行构建、界面实施、提交或推送。
