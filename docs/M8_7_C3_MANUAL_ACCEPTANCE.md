## 2 证据与结论

从 [记录模板](M8_7_C3_RECORD_TEMPLATE.json) 创建本轮独立记录，保留模板不覆盖。记录不是可执行计划、审批票据或自动验收器。每项明确操作者、时间、受测输入、预期/实际、状态、截图/日志路径和哈希。截图避开密钥输入、账号/个人路径及非测试项目内容；原始证据仅本机保留，分享需另行确认。

状态为 `not-executed`、`passed`、`failed`、`blocked`；受阻必须有原因，不能归入通过。未知字节数/用量/耗时留 null，不填 0。一次连接成功不等于领域编辑正确；模型返回不支持操作应记录原拒绝，不修改响应或反复抽样取绿。重试需说明原因、独立授权并保留原失败。

领域记录关联实际 request/session/document/revision、review fingerprint、原回执 `ProposalId/Fingerprint/Status/Code/Changed/ExecutionRevision/RecoveryRequired` 和前后字节哈希；提交前取消可能没有回执，不捏造成功记录。界面仅展示最近 4 条、服务最多保留 64 条，及时保留必要本地证据。UI 不显示的字段标为不可直接观测，并关联同输入的原测试/审计证据，不能反射注入、伪造 UI 事件或从截图推测。

扩展关联原 workflow/plan/source、bundle/capture/recipe/source SHA、job/task/receipt 指纹与终态。C2 的 `M87-JOINT-*` 和 SDK `joint-receipts.json` 是自动用例证据，只有相应用例实际运行后才存在，不预填为人工结果。

### C3-01 候选启动与桌面交互

1. 正常启动已登记的候选 EXE，加载测试项目；记录实际进程、窗口和错误，不启动正式安装替代候选。
2. 用真实鼠标/键盘检查顶部菜单、项目名、AI 工具栏和弹窗；检查中文输入、焦点切换、分页、100/150/200% DPI、窗口缩放/最小化恢复。记录显示环境实际可用的项，不虚报跨屏覆盖。
3. 保存测试数据，正常关闭并重新打开同一候选/项目。确认选择、文件内容及资源引用按实际合同恢复；保存失败保留原目标与日志，不采用非原子覆盖。

### C3-02 模型配置与连接

入口为 **模型工作区 / 连接与完整审批**。未加载项目时应可配置/诊断，但领域目标操作不可用。

1. 远程提供商当前只有 DeepSeek；密钥只在专用掩码输入框输入，保存不联网。配置属于编辑器会话，不绑定项目；不承诺跨重启持久化。其他提供商是扩展方向，不在此验收为已实现。
2. 本机模式使用界面支持的 literal-loopback 端点；模型服务由用户单独准备，不自动启动/下载。只有用户批准启动本地服务后才能把它作为本轮输入。
3. 在本次外发/可能费用获批后，点击 **准备单次连接诊断审阅（不发送）**，阅读全部页，再由人点击 **批准固定诊断外发与可能费用，调用一次**。原上限：一次、64 输出 token、10 秒、16KiB 响应，无自动重试。
4. 对照实际配置和诊断码/HTTP 状态/字节数；未报告用量记未知。配置过期、旧调用未排空或按钮禁用时记录原因，不绕开 UI。
5. **撤销凭据与批准 / 断开 / 重试回收** 只撤销本机会话权限，不能收回已发送内容或吊销服务商密钥。确认不会自动再发请求；重试回收须为明确人工动作。

### C3-03 场景

1. 在测试项目中选中已有对象，记录 UUID/变换/文档 revision，选择 **场景所选对象**。任务限该对象的明确属性修改，不让模型选择额外对象或扫描项目。
2. **生成完整外发审阅（不发送）** → 阅读全部页/接收方/完整请求 → 人工 **允许外发并调用一次**。关闭审阅或未批准时对象和历史不得变化。
3. 返回后 **显式刷新完整差异**；核对精确对象、变换值、额外操作和原权限。只有与任务一致且原合同支持的提案才 **确认差异并交给原事务一次**。记录原回执、Inspector/视口及一次历史增长；Undo/Redo 分别恢复准确前后值。
4. 用独立请求检查取消或在用户修改/切换选择后旧提案不可提交。取消不撤销已经提交的修改，不把拒绝记成已完成目标编辑。

### C3-04 动画

1. 准备有骨架/Clip 的已保存测试图，处理未提交草稿。按原动画面板的人类配对流程授予精确图只读范围，不能由模型自配对。
2. 选择 **当前动画图**。当前入口发送摘要且默认模板为重命名，并不自动上传全图/骨骼；先核对外发内容是否足以支持所请求参数/连线。不足则记录缺口，不暗中追加上下文或声称已复现 C2 注入测试。
3. 对支持的返回草稿，依次 **显式准备并查看动画资源（本机读取，不写文件）**、阅读完整候选/依赖/哈希/受众、另输精确图 UUID、**批准此动画资源并生成原事务差异（不提交）**，最后独立确认原事务。
4. 对照原图和保存后图的端口/类型/参数，使用原 **准备独立真实角色预览**、运行/暂停/单步观察。未批准、取消、Undo 时不应用候选播放结果；Redo 恢复。独立预览不等于 World Play、编辑器画布合成或目标机性能。

### C3-05 UI

1. 打开已有测试画布和确定元素，完成原文件/字体/图像权限；选择 **当前UI文档**，限定布局/样式目标。
2. 按场景相同的外发→完整差异→原事务流程操作，核对实际画布、Inspector、文件内容和单次历史。取消/撤销文件权限后旧提案不能写入。
3. 用 **适应画布**、**1:1**、窗口尺寸/DPI 变化检查位置、裁切、文本与输入命中；保存测试副本、重新加载、Undo/Redo。C2 的 CPU 布局结果不代替本项视觉/交互确认，不恢复已移除的 Figma 参考。

### C3-06 资源

1. 选择无 generation/subassets/dependencies 的根资产，点击 **查看所选资产完整元数据（仅本机）**，需要时 **重新校验原文件与版本（不发送/不写入）**。已导入根/子资产被拒是当前边界，不为测试放宽。
2. 选择 **所选资产settings草稿**，独立审阅外发的完整 metadata/相对路径/哈希及最终 settings 差异。提交后只允许 settings 和一条原历史改变；没有自动导入、下载或源文件修改。
3. 人工另行走资产面板 **Prepare read-only source plan** → 精确 source 审阅 → **Start approved import** → **Prepare candidate publication** → 完整报告/必要身份确认 → **Commit imported generation (Undoable)**。原 UI 若不能为该已有根提供所需授权，记为功能缺口，不能以测试直接调用补成“人工通过”。
4. 检查 asset UUID、采样设置、源哈希、派生代次与子资产引用。按原 placement/assign 操作检查视口；导入与 AI settings 是两次原事务，分开 Undo/Redo。源变更或代次不匹配必须重新准备，不批准旧候选。
5. 关联 F 的运行时闭包/NCP 证据；完整 Player 发布包、实际渲染与部署独立结论，不能仅凭导入成功勾选。

### C3-07 扩展

1. 使用匹配的 extensions/ai-extensions 候选、指定原/候选源码目录和明确文件集。**读取指定文件并审阅（仅本地）**，逐页查看前后完整内容、指纹、字节及路径；**重新核对来源并记录本次已审阅**。
2. **导出已审阅副本（不构建、不安装）**，记录 bundle SHA；选定原工作流后 **交接到当前工作流（不捕获、不构建、不批准）**。交接不是审批票据。
3. 原完整捕获助手、离线依赖准备、构建、合同测试、原生准备、宿主测试各自走独立审批。阅读固定工具/配置/路径/输入集后 **批准此固定作业（60秒，单次）**，再 **启动下一条已批准作业**。缺缓存包明确阻断，不能隐式联网 restore。
4. 含 PS5.1 的 SDK 执行安排在 F 主体终态报告后；之前仅准备本清单。执行后关联四类原回执/审计、reviewed marker 和 Editor/Player 同配置模块/完整包集合证据，不把编译成功当成运行成功。
5. 失败保留原来源/输出/日志及持有状态；修复需新捕获和新审批。安装、替换正式 EXE、重启分别授权，非本清单的隐含动作。

### C3-08 取消与关闭

使用测试请求分别观察发送前取消、进行中取消、结果返回后取消、切换文档/项目、正常关闭。不得旧结果串到新目标，不得自动重试/再授权；已完成命令不自动 Undo。记录排空、原始错误、外层持有与扩展持有，关闭失败不能显示“无残留”或提前释放依赖。进程未结束时保留精确身份，不因清单允许取消而推定获准强杀。
