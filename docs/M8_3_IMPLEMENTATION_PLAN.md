## 边界

C# 编辑模型和原 EditSession/领域事务仍是唯一写入权威。AI/模块仅交付不可信提案，不读取 live World，不自动获批。生成元数据是描述，不是权限。Python、gRPC、模型连接仍可选；默认产品不能因本阶段引入解释器、联网、模型费用或任意执行入口。无旧 SceneWorld/格式兼容层。

实现过程中只做静态/编译检查，新增用例登记不运行；按用户策略在整体阶段结束统一测试。不得通过部署版 Build 包装器进行“无部署验证”。本轮不自动提交、推送、更新 EXE。

## A：编辑来源和只读预检

1. 精确绑定项目、宿主、EditSession、DocumentSession、文档代次/修订、脚本目录代次、选择状态和撤销代次；不以虚构 World/tick 代替编辑身份。
2. 首先支持原 `ncma.scene.transaction` 的本地草稿预检；复制完整输入，闭合信封、严格 UTF-8、重复键和深度检查，64KiB、原128操作上限。
3. 调用原 `DescribeRequestImpact`，不复制领域实现，不 Commit、不产生历史。返回有界复制输入、影响和内容指纹；有效期60秒、终身256个ID、撤销不清除ID墓碑。校验失败也消耗已登记ID。
4. 首增量不输出完整 before/after diff、不校验读取授权、不产生执行票据。服务只能在可信本地调用，不能把本地预检数据当作已授权远程观察。尚未接正式按钮、模块回包或 MCP。
5. 宿主生命周期及 C#/Python 模块编辑来源 v2 已实现/编译；下一步接批准的观察范围和单次 ModuleSession 领取。搬移包与跨语言功能验证集中整体阶段末，不伪造身份、不默默兼容旧格式。

## B：场景确认与原事务

接入既有能力目录/端点/审批范围。批准只读观察 → 发起模块任务 → 校验原请求及来源 → 领域校验与完整 diff → 本地人工精确确认 → 原事务 → 原 Undo/Redo。确认不能由回包布尔值代替；权限撤销、目录替换、Play、文档切换和迟到结果均失效。普通事务、逐UUID删除、可执行脚本绑定的确认分开；不得以当前只读预检的成功作为授权。

确认票据绑定确切有效负载/来源/作用域/资产身份，单次消费；提交前重新验证。保持原权限、128操作/64KiB和历史预算；规范化改变值时须重新展示确认，不把新值算作旧审批。

## C：资产、动画与 UI

逐域接既有目录、inspect/validate/propose/transaction，不建立第二工具网关。资产固定 UUID/代次/SHA；动画绑定骨架/图/片段身份；UI 绑定原文档/资源版本。使用 E6 描述符，不反射私有脚本状态。

场景历史与文件资产发布不是全局原子事务：每域定义提交点、失败状态、补偿权限和证据；不自动 Undo 后续用户工作。未接入域明确拒绝，不回退任意工具名。

## D：正式编辑器与统一验收准备

正式 AI 区展示来源、范围、提案、完整差异、过期/取消及原提交回执；保留“未接入推理服务”，实际模型接入仍属 M8.4。旧观察/回包在源变化时隐藏。工具不能自我审批；本地面板与既有 MCP 授权入口清晰分离。

准备原服务链集成用例：实际读取权限/范围、越权、重复、过期、正常提交/Undo/Redo、删除独立授权、资产漂移、撤销/重入/线程、异步取消/保留资源、无Python产品路径。原渲染/物理/代码生成/调度门禁保持；全部实现后统一运行，不用编译替代验收。
