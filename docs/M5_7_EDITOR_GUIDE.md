# M5.7 Editor使用说明

2026-10-07。适用现役`out/bin/NcmaEngine.exe`的场景与UI制作自动候选；完整输入法、目标机、性能及长稳尚待验收。

## 入口

以正常项目启动Editor（项目包含资产目录）。顶部“工具”或“窗口”→“UI创作工作区”；窄窗可在“菜单”找到同一入口。无项目资产服务时入口禁用，不伪造可写文档。UI工作区“场景工作区”按钮返回原场景，切换不会Start/Stop/Step Play。

菜单继续左对齐文件/项目/编辑/工具/游戏/AI/窗口/帮助，项目名位于系统窗口标题“NcmaEngine - 项目名”，空白使用“未命名项目”。AI工具标题右侧显示未接入推理服务，无云入口。

## 新建、打开和写权限

1. 在“UI资源/文档”输入项目相对`.ncmaui`路径，或使用本机文件选择器。只接受严格v1，不导入旧场景/UI格式。
2. 选择“审阅新建/打开”。核对路径、文档UUID、规范化文档hash及依赖UUID。
3. 输入显示的完整文档UUID。打开可不勾写权限，以只读查看；新建必须明确批准写入。已有文件不会被新建覆盖。
4. 需要编辑时勾选此精确文件写入并确认；批准只对应当前项目/文档/代次，不授予Agent文件权限。Play冻结时无法批准写入或提交。

一次只有一个活动文件。确认编辑直接经原子文件事务保存，不另建延迟保存历史。Ctrl+S确认当前草稿或校验已保存文件；未改变时不新增Undo。Ctrl+Z/Redo使用场景、资产、UI共享的唯一历史，并重新检查原权限。

## 字体与图像

在资源区填写项目内字体/图像相对路径。字体必须填写许可声明；再分发选择是用户声明，不是法律验证。点击审阅，核对精确UUID/hash/source，输入该UUID并批准。图像使用现有可信导入数值库实际解码，字体使用NcmaText实际解析；不是自动系统字体或在线资源服务。

新资源UUID可留空分配。重启打开已有文件时，先依据显示的依赖UUID批准同一资源：把UUID填入“资源UUID”，再审阅和确认。文件只存UUID，目录尚不是可移植cook或自动持久映射。缺资源会停止对应UI准备并显示诊断，不能用默认图/字体掩盖。

批准资源后选择对应元素，在Inspector设置字体/图像UUID。Action只能使用可信C#启动声明的语义名；默认`preview.test`仅供本机观察，不执行游戏代码。

## 画布与编辑

- 左侧为UI内部图层，不是场景父子树。Ctrl切换多选，Shift图层范围选择，最多64项；Canvas中Shift追加/框选，祖先/后代同选只变换顶层选集。
- Space加左键或中键平移，滚轮以指针为中心缩放；适应画布、1:1和F聚焦选择不写文档。可见尺寸有额外安全限制，不保证所有DPI组合都到800%。
- 选择Move/Resize/Rotate工具。Resize支持八个手柄，Free布局可操作；Hug/Fill轴要显式改Fixed，auto-layout拖动用于排序，不偷偷转成绝对布局。
- 吸附优先父容器，再同级元素，最后8单位网格；约6屏幕逻辑像素阈值，辅助线不保存。Alt关闭吸附；旋转默认15度。
- 对齐/分布/Group要求可保持几何的同父空间。Group要求连续图层，拒绝不能保持语义的组合。root不能删除，子树删除须输入准确UUID；场景仍只单对象删除。
- Inspector支持布局/样式/资源/Token/注册Action。长文本按Unicode安全页编辑，但完整文本一起校验/Undo，不截掉其他页。它不是完整富文本/游戏TextInput选区或IME实现。
- 拖动/属性激活期间只更新草稿，结束一次提交、一次Undo。Esc、失焦、切换、撤权、冲突或错误取消；不允许第二个作者草稿或Agent写前缀穿透。

底部工具有1280×720、1920×1080、1080×1920、640×360预设，以及64–2048尺寸/DPI0.25–4/安全边0–32自定义。安全区必须小于逻辑尺寸，非法值保留上一份有效设置。小窗使用画布顶端“聚焦画布”，再次点击恢复面板；自动收起AI不会授予权限。

分隔条与AI显示状态保存在项目本机`out/user/editor/workspace.json`，无项目时使用程序目录对应本机路径。它不写场景或Undo；坏文件保留并报告，不自动覆盖。没有自由docking、多窗口或多UI文档。

## 独立测试和故障

进入“独立测试”使用隔离UiRuntime，停用作者变换；鼠标/Tab/激活/基础文字输入只进入本机有界观察，不回调活动World/Play。退出或重置只重建UI实例，Play tick/session不变。UI作者提交仍受Play冻结。

静态UI使用驻留数据和缓存目标，GUI每个可见frame取得精确呈现租约。UI错误不伪造新画面；GPU关闭失败保留资源并进入RecoveryRequired，明确关闭可重试，不能先卸载插件或强制清理文件。共享设备故障应用fail-stop，不声称solver回滚。

场景/MCP精确审批仍在场景AI区域；UI区域显示真实端点/连接/有效授权摘要，可返回审批。UI Agent写工具留到M5.9，Python推理未接入。项目Player HUD/cook/发布留到M5.10。

构建与测试始终使用`Build.bat -Configuration Debug`、随后`Build.bat -Configuration Release`。Skip模式不部署。证据和未通过门禁见[M5.7交付记录](M5_7_DELIVERY_REPORT.md)。
